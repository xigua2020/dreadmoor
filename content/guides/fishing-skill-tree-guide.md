The fishing tree is the cheap tree — and that is exactly why players misprioritize it. This guide lays out every fishing research node in the demo, what it costs, and the order that keeps the main quest moving. Recipes and materials are in the [recipes](/crafting/recipes/) and [blueprints](/crafting/blueprints/) databases.

## How Fishing Research Works

Fishing upgrades are researched in the Mastery interface with **Torn Pages** (inventory: Scraps of Knowledge), then crafted at the **Craft Table**. The fishing tree is unusually cheap: every node except one costs **0 pages**.

## The Fishing Nodes

| Node | Type | Pages | What it gives you |
|---|---|---|---|
| Old Rod | Rod | 0 | Starting rod — finishes the opening contracts |
| Earthworm | Bait | 0 | Snapper-only starter bait |
| Wind-Up Tin | Bait | 0 | Standard peaceful lure — Softgrazer contract |
| Rainbow Fin | Bait | 0 | Standard predator lure — Harpooner contract |
| Sturdy Earcrawler | Bait | 0 | Peaceful trophy chance |
| Flaming Belly | Bait | 0 | Predator trophy chance |
| Braided Line | Line | 0 | More line-tension margin |
| Reinforced Rod | Rod | 0 | Tires fish faster |
| Baitcasting Reel | Reel | 0 | Faster line recovery |
| Deadly Tick | Bait | **5** | Narrow predator bait (Bonescar, Bully, Rammfish, Stonegnawer) |

## Recommended Order

1. **Wind-Up Tin** — gates the three-Softgrazer contract.
2. **Rainbow Fin** — gates the three-Harpooner contract.
3. **Braided Line** — the best comfort pick; fewer snapped lines on class 3 fish.
4. **Reinforced Rod / Baitcasting Reel** — fight quality, either order.
5. **Ship tree** — Weak Hull Protection and Upgraded Engine (2 pages each) before anything optional.
6. **Deadly Tick** — last. Its recipe needs Sharpfin Flesh, so it is a post-route project by design.
